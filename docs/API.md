# API Summary

Chwezi SDLC Documentation does not expose a runtime API. Each skill is a `SKILL.md` playbook that a coding agent follows, using the skill's `logic.prompt` where one exists; eight Waterfall skills keep a Python helper (for example `python3 02-requirements-engineering/waterfall/05-feature-decomposition/feature_decomposition.py`). The deterministic part is a command line: `python3 -m engine validate projects/<ProjectName>` and the other `python3 -m engine` commands listed in `README.md`. Users integrate the engine into their IDE or CI/CD pipeline by invoking those commands so the automation can target the active `projects/<ProjectName>/` workspace.
